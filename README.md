# Espi Keep Bags Open

Bags only close when you close them.

If you have your bags open, the game often closes them for you: talking to a
vendor, opening the mail, pressing Escape to close another window. This addon
reopens them. If you close them yourself, they stay closed.

## Usage

- `/kbo` or `/keepbags` toggles the addon.
- `/kbo on` and `/kbo off` set it explicitly.
- `/kbo status` shows whether it is on and how many bags it is keeping open.
- `/kbo config` opens the settings page (also under Options > AddOns).
- Retail: click the addon compartment entry (minimap) to toggle.
- Whatever bags are open when you turn it on are the ones it keeps open.

## Supported versions

Retail and Classic.
